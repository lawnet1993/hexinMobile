# 消息列表长标题与日期间距真机复验

日期：2026-09-09（Asia/Shanghai）

## 问题

realme 真机当前真实会话中，长群名省略号与右侧“昨天”几乎相连，日期容易被误认为群名的一部分。短单聊标题不明显，但共用同一行约束。
