## 修复

本机选择的图片和普通文件会先进入账号隔离的加密存储。对于尚未被草稿或待同步申请持久引用、仅由当前新建页面拥有的附件，现在会在以下边界清理：

- 不支持离线草稿的页面直接退出；
- 用户主动删除尚未保存的附件；
- 单附件字段重新选择文件并替换旧附件；
- 提交成功并完成跳转；
- 网络不可用且申请已可靠转入 Outbox。

已有草稿附件继续由草稿保存/删除流程管理，已有待同步申请附件继续由 Outbox 管理，不会因返回页面或一次提交失败而提前删除。
