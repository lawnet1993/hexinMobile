# 移动端当前构建五个主入口复验（2026-09-06）

## 结论

当前 Profile APK 在同一登录态下重新逐页运行工作台、消息、待办、通讯录和“我的”。五个主入口没有因近期 IM、OA、附件流和进程恢复改动产生布局或交互回退，当前模拟器视觉与结构复验通过。

本结论只覆盖当前 Android 构建；当前 Windows 客户端位于无影云桌面，本轮电脑控制通道无法取得实时窗口，因此不把历史桌面截图当作最新桌面的独立对照证据。realme 真机仍锁屏，也不把模拟器截图替代为真机手势与键盘验收。
