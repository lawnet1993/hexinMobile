# 587 添加好友链路与桌面端能力语义对齐

## 当前结论

本轮真实打开当前已登录桌面端 v1.0.80 的通讯录和“添加好友”面板，只读核对交互后，定位并修正移动端结果动作判断错误。

- 桌面端真实链路为“添加好友 → 输入完整终端账号 → 查找 → 根据服务端能力显示发消息或申请好友”。
- 桌面端使用服务端 `canStartDirect` 决定结果动作，而不是用 `isFriend` 猜测。
- 移动端原实现按 `isFriend` 显示动作，可能把允许直接会话的成员错误显示为“申请好友”，造成重复申请或链路绕远。
- 移动端现已改为与桌面端一致：`canStartDirect=true` 显示“发消息”，否则显示“申请好友”。
- 精确账号搜索、排除当前成员、单聊创建和好友申请接口均保持不变；群聊没有进入该链路。

当前判定：**逻辑、自动化、静态检查、构建和覆盖安装通过；真机触控复验待正常解锁**。
