# 真机工作台与桌面 v1.0.105 边界核对（2026-09-08）

## 基准

- 桌面端：用户现场确认当前运行版本为 **v1.0.105**。
- 移动端：当前 Profile APK，realme 真机，Test Terminal 01。
- 桌面控制服务本轮未配置成功，因此不使用仓库内旧桌面源码冒充最新运行窗口；仅使用用户提供的 v1.0.105 真实窗口截图核对可见功能边界。

## 工作台

真机当前工作台包含：

- 公告入口；
- 常用应用及全部应用入口；
- 待我处理、我发起的；
- 桌面基准中可见的打卡、请假、加班、出差、报销、补卡、请款和借支等业务入口。

移动端当前没有显示“常用站点”、站点卡片、隧道状态、连接诊断或日程模块，符合移动端只接收站点相关提醒、不建立 TUN、不直接打开企业站点的既定边界。

## 全部应用

真机当前按后台目录显示：

- 考勤：打卡、请假审批、加班审批、出差审批、补卡审批、考勤申诉；
- 费用：报销审批；
- 财务：请款审批、借支审批；
- 采购：采购申请；
- 行政：用印申请。

未发现站点访问、日程、工作群组、安全工具或桌面网络能力被错误放入移动端全部应用。

## 页面密度

- 工作台应用图标采用无外边框的紧凑网格。
- 首页公告保持单行卡片，没有占用大块首屏空间。
- 首页待办“处理”使用紧凑按钮，不再使用大面积主按钮。
- 待办标签栏保持单行横向布局；长标签可横向滚动。
- 待办搜索框、筛选按钮和状态标签均保持移动端紧凑尺寸。
