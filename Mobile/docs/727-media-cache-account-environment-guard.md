## 修正与边界

- 复现旧账号图片、媒体、OA 缩略图响应迟到后清掉新账号内存缓存：原实现 `cache.write(oldAccount, ...)` 会切换整个缓存。三个回归先失败，加入 Provider 代际检查与安全存储身份复核后通过。
- 同一消息/图片 ID 的摘要变化不应复用旧内存字节；缓存键加入摘要。该用例同样先失败后通过。
- 缓存身份改为应用环境、账号、IM 地址、OA 地址的 SHA-256 命名空间，不含密码、令牌、设备指纹。视频封面磁盘键原来只有封面 ID/摘要，现也带此命名空间。
- 账号、服务地址变化或退出会清除活动内存缓存；普通 Token 刷新不更换缓存、不要求重拉所有图片。
- 图片、OA 缩略图、视频的磁盘读、网络返回、抽帧、缓存写入等异步边界复核当前身份；安全存储先改变、UI 尚未发布新账号时也会丢弃迟到结果。已开始的磁盘写仍只写原账号命名空间，不发布给新账号。
- 媒体读取使用已有有界重试策略：网络/服务端临时故障最多自动重试两次，会话变更不自动重试旧请求。视频封面失败后尝试抽帧前也检查身份。
- 不迁移、不删除旧版磁盘缓存；新命名空间首次显示会重新获取一次。后续使用现有有界内存/磁盘缓存。没有新增业务消息、没有清空数据库、没有变更账号密码。
