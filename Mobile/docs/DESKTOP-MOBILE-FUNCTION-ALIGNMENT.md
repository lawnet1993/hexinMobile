## 本轮已确认问题

- 移动端“添加联系人”误用了 `/api/im/search`，桌面端实际使用 `/api/im/members/search`。
- 好友申请只可发送，原移动端没有查看、接受和拒绝入口。
- 弹层连续关闭并刷新数据会触发 Flutter `_dependents.isEmpty` 红屏。
