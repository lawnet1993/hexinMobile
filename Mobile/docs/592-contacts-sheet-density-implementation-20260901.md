# 592 通讯录底部抽屉样式统一

## 当前结论

通讯录的“添加好友”和“选择部门”已移除系统默认拖拽条，统一为覆盖底部 Tab 的根导航抽屉，并使用应用内一致的紧凑拖拽条、标题和关闭按钮。

- 添加好友仍要求输入完整终端账号，34dp 搜索框和原有好友/可直接会话权限判断保持不变。
- 选择部门保留真实部门树、成员数量和 44dp 部门行，不改变筛选数据来源。
- 两个抽屉均启用安全区，不使用居中弹窗。
- 本轮没有查找账号、发送好友申请、创建会话或修改服务端数据。
