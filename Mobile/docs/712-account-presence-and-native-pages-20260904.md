## 账户状态修复

真机 RMX3366 的“账户与安全”显示“已登录·离线”。检查源码发现 `watchMemberPresence(...).online == true` 将三态值压成 bool，未知、缺少观察和超过有效期的状态全部变成 false。没有导出当时真机内部投影，因此不把该截图单独当作服务端在线状态证明。

新增五个 widget 用例：未知值、过期在线、过期离线、新鲜在线、新鲜离线。修改前三个用例失败，后两个通过，直接证明未知状态被误标离线。

修复保留 nullable 状态：

| 依据 | 显示 |
| --- | --- |
| 无会话 | 已失效 |
| 同步连接中 | 已登录·同步中 |
| 同步不可用 | 已登录·同步中断 |
| 同步可用且有效观察为在线 | 已登录·在线 |
| 同步可用且有效观察为离线 | 已登录·离线 |
| 同步可用但没有有效在线观察 | 已登录 |

没有通过硬编码“在线”掩盖未知状态，没有延长在线观察有效期，没有改变真实会话的有效期或登录协议。现有同步连接/中断提示保持区分。
