# 869 · 无扩展名图片本机处理补强

时间：2026-09-09（Asia/Shanghai）

## 问题

常规 Android 文件选择结果可通过文件名扩展名识别图片，不依赖系统返回的 MIME。但部分相机、分享或文档提供器会返回无扩展名显示名称；旧逻辑会把这类图片当成普通二进制文件，导致本机图片压缩策略未生效。

## 改造

- 有已知扩展名时保持零额外 I/O，直接使用现有类型映射。
- 无扩展名或未知扩展名时只读取最多 512 字节文件头，不读取整个文件到 Dart 堆。
- 识别 JPEG、PNG、WebP、HEIC/HEIF 后进入原有本机压缩流程。
- 识别 GIF、SVG 后仍走原始图片文件流，避免动画丢失或矢量图栅格化。
- 未知内容继续作为 `application/octet-stream`，不会误压缩普通文件。
- 文件头探测后的上传/暂存会重新打开数据流，现有 multipart、加密 Outbox 与 OA 加密草稿协议不变。

改造已同时接入聊天图片选择和 OA 附件选择。
