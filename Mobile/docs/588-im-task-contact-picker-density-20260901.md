# 588 IM 共同任务与联系人分享抽屉密度整改

## 当前结论

本轮继续清理 IM 中残留的默认大号控件，完成单聊共同任务和联系人分享两条链路的移动端紧凑化。

- “新建共同任务”改为覆盖底部 Tab 的根导航抽屉，增加自定义拖动提示、16dp 标题和关闭入口。
- 任务名称输入框固定为 36dp，使用浅灰填充并移除描边。
- 优先级由松散 ChoiceChip 改为 36dp 四段选择。
- 取消/创建按钮右对齐，创建按钮固定 36dp、高度可测且宽度小于 120dp。
- “分享联系人”改用 34dp 搜索框、50dp 人员行、17dp 头像，并展示服务端姓名、部门、账号和在线状态。
- 两个抽屉都使用根导航和安全区；联系人搜索默认不主动弹键盘。
- 共同任务继续只在单聊展示，群聊附件菜单不出现该动作；联系人分享仍可用于单聊和群聊。

当前判定：**实现、自动化、静态检查、构建和覆盖安装通过；真机触控复验待正常解锁**。

## 自动化覆盖

1. 单聊任务页和附件菜单均能打开 `shared-task-create-sheet`。
2. 任务名称输入框与创建按钮实际高度均为 36dp，创建按钮宽度小于 120dp。
3. 群聊附件菜单不显示“创建任务”，防止单聊/群聊能力混用。
4. 联系人分享打开 `chat-contact-picker-sheet`，搜索框实际高度为 34dp且默认不弹键盘。
5. 真实联系人行实际高度为 50dp。
6. 两个抽屉均可安全取消，没有创建任务或发送联系人名片。

## 真机边界

真机解锁后需要在真实单聊中打开“任务 → 新建”和“附件 → 联系人”，核对键盘避让、底部 Tab 覆盖、人员在线状态与小屏滚动；只打开后取消，不创建共同任务、不发送联系人名片。
