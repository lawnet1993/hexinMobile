# 848 · 聊天多图本机压缩与增量 Outbox

时间：2026-09-09（Asia/Shanghai）  
范围：Flutter Mobile / IM 图片发送

## 结论

聊天图片继续执行“本机压缩后上传”，且多图选择不再先把全部压缩结果同时保留在 Dart 内存。客户端现在按选择顺序逐张读取、压缩并立即加密写入账号隔离的 Outbox；上一张完成暂存后才处理下一张，最后仍作为同一条 1–9 图消息发送。

普通文件、视频和音频保持原始文件流，不做有损压缩，也不转换为 Base64。头像继续使用裁剪后的本机压缩结果。

## 失败与清理

- 任一图片读取、压缩或暂存失败时，本批次已写入的加密临时文件会被删除。
- 成功入队后由现有 Outbox 顺序发送、确认替换和重试机制接管。
- 单张压缩结果写入加密文件后即可释放，不随选择张数线性叠加驻留内存。
