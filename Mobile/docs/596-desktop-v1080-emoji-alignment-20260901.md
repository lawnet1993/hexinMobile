# 596 桌面 v1.0.80 纯表情消息对齐

## 当前结论

已直接操作当前正在运行并已登录的桌面端 `v1.0.80`，而不是依赖本地旧桌面源码。桌面端更新说明明确要求：纯表情消息使用更大尺寸，表情与文字混排时保持普通文本样式。移动端原先所有文本消息均使用同一字号，本轮已补齐这一差异。

移动端现在只对 `kind=text` 且内容完全由 Emoji 组成的消息使用 30sp；普通文本、表情与文字混合消息、附件说明和链接仍保持原有字号。识别覆盖 Unicode 扩展表情、变体选择符、肤色修饰、ZWJ 组合家庭表情、地区旗帜、标签序列和数字键帽，不能被单独的连接符或普通数字误判。
