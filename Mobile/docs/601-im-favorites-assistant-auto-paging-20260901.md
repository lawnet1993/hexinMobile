# 601 IM 收藏与群发任务连续滚动分页

## 当前结论

IM“我的收藏”和“群发助手”的任务记录已移除手动“加载更多”按钮，改为接近列表底部自动读取下一页。短首屏会自动补齐；长任务记录只有滚动接近末端才请求下一页。分页失败保留已显示内容，并在下一次真实上滑时重新请求对应页，不会自动形成错误重试循环。

## 实现

- “我的收藏”继续使用 `imFavoritesPageProvider(page)` 的服务端页码契约，按 `messageId` 精确去重。
- 收藏第一页不足一屏且 `items.length < total` 时自动补页；下一页为空时结束本地分页，避免服务端总数漂移导致循环。
- 收藏刷新会同时清理附加页、失败阻断和本地终态。
- 群发助手由外层页面滚动驱动任务分页，嵌套接收人列表不会误触发任务请求。
- 群发任务按任务 ID 精确合并；新建或取消任务后的页面重置语义保持不变。
- 两处均使用 240dp 预加载距离、并发加载互斥和逐页错误缓存失效。
