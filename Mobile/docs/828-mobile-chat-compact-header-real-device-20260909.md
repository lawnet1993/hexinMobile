# 聊天页紧凑标题栏真机复验

日期：2026-09-09（Asia/Shanghai）

## 问题

聊天页顶部原先使用三个默认尺寸操作按钮，在手机宽度下会挤压单聊名称，真机只显示 `Test Terminal ...`，与移动端需要压缩信息元素和操作按钮的要求不符。

## 调整

- 会话标题固定为 16sp、`w600`，仍保持单行省略，不增加标题栏高度。
- 收藏、搜索、更多统一为 44 × 44dp 点击区域，图标为 20dp。
- 保留移动端可触达面积，没有通过缩小点击区域换取视觉空间。
- 不改变单聊/群聊边界、消息渲染、历史加载、Presence 或已读逻辑。
