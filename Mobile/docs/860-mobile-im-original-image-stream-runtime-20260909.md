## 修复

- IM 图片批次新增逐张流式加密暂存接口。
- JPEG、PNG、WebP、HEIC、HEIF 仍先在本机压缩，再把压缩结果流式写入 Outbox。
- GIF、SVG 保持原始文件名、MIME 和字节流，不在 Dart 堆中一次性读取整个文件。
- 多张图片继续归属于同一个图片消息，不降级为普通文件消息。
- GIF/SVG 内联图片上限为 50 MiB；超过后提示可改用普通文件发送，普通文件仍使用 512 MiB 边界。
- 批次中任一图片准备失败时，清理该批次已经写入的加密文件，不影响既有 Outbox。
