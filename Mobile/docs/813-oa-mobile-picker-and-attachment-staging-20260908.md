# OA 选择器与附件本地暂存复验（2026-09-08）

## 结论

- 后台 Schema 的单选字段在移动端使用底部选择面板；本轮真实请假类型显示年假、事假、病假、调休，没有桌面下拉框悬浮层。
- 日期选择使用移动端底部日历，取消/确定按钮保持紧凑，页面上下文仍可见。
- OA 附件直接调用 Android 系统文件选择器，通过系统授权返回单个文件 URI；不申请整盘存储权限，也没有先弹出自制的大型附件菜单。
- 选取现有 905.7 KB PNG 后立即回到表单，显示缩略图、文件名、大小和删除入口，并自动保存草稿；没有提交审批或写入服务端业务数据。
- 图片和普通文件不会以 Base64 放进业务表单或数据库：图片在上传前按阈值本地压缩，普通文件加密暂存并以流式 `multipart/form-data` 上传。

## 当前压缩与上传边界

- 头像：每次都缩放为 256 px WebP，200 KB 头像不会被直接拒绝。
- IM/OA 图片：超过 2 MiB 时在本机分级压缩，最长边从 2560 px 逐级降到 1280 px；不足阈值时保留原图，避免小图片反复有损转码。
- Word、Excel、PPT、PDF、音视频及其他文件不走图片压缩，也不把整个文件读成 Base64 字段；从加密暂存文件创建 Multipart 流。
- 本轮 905.7 KB PNG 未压缩符合当前阈值，不是压缩失败。十余 MB 真机照片仍需真机解锁后补选取、峰值内存、压缩结果和上传进度实测。
