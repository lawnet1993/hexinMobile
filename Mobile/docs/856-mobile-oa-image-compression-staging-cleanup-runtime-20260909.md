# 移动端 OA 图片压缩、暂存与清理运行时验收

> 日期：2026-09-09  
> 设备：Android 模拟器 `emulator-5556`  
> 场景：请款审批图片附件；未提交业务申请

## 结论

通过。OA 动态表单已真实验证本机大图压缩、缩略图生成、账号隔离加密暂存、删除附件清理和草稿清理。整个过程没有把 17.46 MB 原图直接交给服务端，也没有新增审批申请。

## 实测结果

- 系统文件选择器识别原图：JPEG，6000 × 4000，17,457,727 字节。
- 点击文件后约 4.1 秒回到表单，附件行显示 2.0 MB，并显示本机缩略图。
- 应用私有加密暂存产生两个文件：
  - 图片正文：2,077,404 字节；
  - 缩略预览：47,720 字节。
- 删除附件后，当前账号附件目录立即归零。
- 页面自动保存产生的本轮请款草稿已删除；草稿箱由 2 条恢复到原有 1 条请假草稿。
- 主机与模拟器 Download 中用于本轮的 17.46 MB 测试原图均已删除。

## 交互核对

- 附件数量使用 `1 / 20`，与后台表单数量限制一致。
- 图片附件使用紧凑行展示缩略图、文件名、压缩后大小和删除图标。
- 添加文件按钮保持移动端尺寸，没有占据整行大按钮。
- 压缩阶段结束后才写入草稿引用，删除附件不会遗留正文或预览。
