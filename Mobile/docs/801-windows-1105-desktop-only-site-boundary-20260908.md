## 桌面更新说明

`v1.0.105` 的发布说明包括：升级时不再弹出 PowerShell 黑窗口；安装器检查并静默安装内置 Visual C++ 运行库；登录页版本检查超时后恢复操作并提示重试。本版为测试环境强制更新。

本轮没有触发下载、安装或管理后台写操作。

## 移动端改造

- “网络诊断”入口改为“站点访问 / 桌面端使用”，进入后只显示紧凑桌面端提醒。
- 站点页面不再拉取或搜索授权站点，不直接打开外部站点，也不显示刷新按钮。
- “网络与安全”页面移除连接状态、重新检测、策略标识、组件版本和上传/下载流量等桌面专属控件。
- 正常入口不再注册移动端隧道；测试专用入口同步移除注册。
- 心跳固定上报 `systemProxyEnabled=false`、`tunEnabled=false`；不再读取隧道控制器而隐式启动连接。
- 帮助与诊断文案改为：授权站点在桌面端访问，手机只负责消息、审批和提醒。
- `access.*`、`network.*` 和 `site.*` 通知仍归入通知中心；点击后进入只读桌面端提醒页，不打开站点。
