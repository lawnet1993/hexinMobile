## 本次变更

1. 默认移动控制面切换到当前桌面实际使用的 API 地址。
2. 存储命名空间加入规范化服务器地址、环境名称和演示模式的摘要；仅修改服务地址而忘记修改环境标签，也不能复用上一环境的安全存储与数据库。
3. 令牌、记住密码、设备标识、推送令牌、加密密钥和 IM/OA 数据库均使用新命名空间。Outbox 附件已有命名空间隔离，随之切换。
4. 补齐图片缓存、视频预览、受控产物与隧道配置目录的环境隔离。
5. 不读取旧的未分区安全存储，不迁移旧 Outbox 或草稿，不删除旧数据。新环境需首次重新登录；同环境重启、注销后设备身份保持稳定。
6. 真实操作发现请款申请人卡片遗漏 `avatarKey`：聊天显示系统预设头像，审批页只显示首字母。补齐预设头像传递，并保留上传头像优先规则；最终包真机已显示正确头像。
