## 定位边界

- 已确认不是单纯的 UI 重绘：桌面消息持久缓存本身就缺记录，也没有因为后续本机发送而补齐。
- 原手机消息已成功落服务器，且桌面当前会话仍可通过消息/同步 GET 200 读到；不能归因于手机没发出或直接认定登录失效。
- 故障范围收敛到桌面入站事件接收、落库及漏消息补拉。统一 Push Gateway 未向桌面投递、桌面过滤同账号事件、接收后未落库等具体原因仍需新版运行诊断/源码核实，当前不作唯一根因断言。
