# 移动端图片本机压缩上传运行时验收

> 日期：2026-09-09  
> 设备：Android 模拟器 `emulator-5556`  
> 场景：IM 单聊图片上传

## 结论

通过。本轮不是仅验证单元测试，而是在系统照片选择器中选择一张 6000 × 4000、17,457,727 字节的 JPEG 图片并真实发送。客户端本机压缩后上传并正常渲染，落地的消息图片为 2,077,244 字节，减少约 88.1%。

## 实测记录

- 原图：JPEG，6000 × 4000，17,457,727 字节。
- 入口：聊天附件抽屉 → 图片 → Android 系统照片选择器。
- 选择器权限：仅获得用户本次选择的照片访问权限。
- 发送结果：会话中生成一条图片消息，时间 23:12，状态为已发送。
- 本地消息图片：2,077,244 字节，低于 3 MiB 目标值。
- 文件标签从 2 增加到 3，消息图片可在当前会话显示。
- 传输仍使用 IM 图片 multipart 文件上传，不使用 Base64。

## 适用策略

- JPEG、PNG、WebP、HEIC、HEIF 可在本机压缩。
- 聊天图片和 OA 图片超过 2 MiB 时触发多档尺寸、质量压缩，目标不超过约 3 MiB。
- 自动修正照片方向，输出时不保留 EXIF。
- GIF/SVG、文档、音视频不进入静态图片压缩链路，避免破坏动画、矢量或原始文件。
