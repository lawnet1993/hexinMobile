# 我的、账户安全与断网状态复验（2026-09-08）

> 2026-09-09 真机增量：realme 真机已经解锁，当前 Profile APK 完成相同页面复验。真实“登录设备”接口也已恢复，旧文档中的锁屏与设备同步阻塞不再成立。

## 结论

当前 Profile APK 在 Android 16 模拟器上通过“我的”和账户安全页面的移动端交互复验：页面未再暴露隧道、站点、网络诊断、完整设备 ID 或设备指纹；修改密码使用底部操作面板，输入框和按钮保持移动端紧凑尺寸，键盘弹出后没有遮挡三个密码字段和确认操作。

## 页面结果

- “我的”只保留个人资料、账户与安全、通知设置、登录设备、外观与语言、帮助反馈、关于和退出登录。
- 用户卡片显示姓名与部门，不在首页重复显示账号。
- “账户与安全”只显示当前账号、设备名称/系统和登录状态；不显示完整 `deviceId`、指纹、Token 或内部接口信息。
- 修改密码从独立大表单改为底部面板，三个密码框约 42dp 高，确认按钮为紧凑操作宽度；成功语义明确为其他设备重新登录。
- 当前服务端同步异常时，“登录设备”显示“暂时无法同步”并提供单一重试按钮，不伪造空设备列表，也不把 IM/OA 同步异常误报为手机网络不可用。
- 账户安全中的状态显示“已登录·同步中断”，保留当前会话，不因网络、超时或 5xx 自动退出登录。
