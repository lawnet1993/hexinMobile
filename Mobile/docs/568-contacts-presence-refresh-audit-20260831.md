# 568 通讯录真实在线状态刷新验收

## 结论

本轮通过。通讯录继续直接展示服务端 IM bootstrap 的 `isOnline/lastSeenAt`，没有根据本机列表或账号名称猜测状态；进入组织、好友或群聊页会立即刷新，手动下拉也会重新请求服务端。并发刷新会合并，离线失败时保留最近一次服务端状态。

## 实现与边界

- 初次进入通讯录立即刷新，不再最多等待全局 25 秒心跳或页面 30 秒定时器。
- 下拉刷新调用服务端 `refreshBootstrap`，不再仅让 cache-first provider 重读本地缓存。
- 同一时刻只允许一个在线状态请求，进入、切换和下拉不会叠加重复调用。
- 组织、好友、群聊、新朋友仍是独立标签；群聊列表只取 `isGroup=true` 的会话。
- 保留紧凑无分隔线联系人列表，在线绿色、离线灰色，头像继续使用服务端数据。
