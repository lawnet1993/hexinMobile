# 589 群成员与发起群聊抽屉密度整改

## 当前结论

本轮完成群成员相关三条移动端链路的统一，并保持所有群聊权限与服务端接口不变。

- “添加群成员”改为根导航抽屉，使用 34dp 搜索、50dp 复选人员行、17dp 头像和右对齐 36dp 操作按钮。
- “从单聊发起群聊”改为根导航抽屉，群名称输入固定 36dp，固定成员和候选成员均为 50dp，创建按钮为右对齐 36dp。
- “查看全部群成员”增加紧凑标题和拖动提示，搜索框固定 34dp，成员行固定 54dp。
- 全部群成员列表移除逐行分隔线，避免通讯录曾出现的黑线式视觉噪声。
- 成员行继续显示服务端姓名、账号、部门、群角色和真实在线/最近上线状态。
- 只有服务端允许创建群组时单聊详情才显示“发起群聊”；只有群管理者才显示添加成员入口。

2. 全部群成员抽屉存在，搜索为 34dp、成员行为 54dp、列表无 `Divider`。
3. 从真实单聊详情打开发起群聊抽屉，群名称为 36dp、候选成员行为 50dp、创建按钮为 36dp。
4. 所有抽屉均只打开后关闭，未添加成员、创建群聊或改变群角色。
