# 839 · 移动端图片压缩失败降级与错误提示

时间：2026-09-09（Asia/Shanghai）

## 结论

头像、聊天图片和 OA 图片继续在本机压缩后以 multipart 文件流上传。本轮补齐原生编码器异常边界：

- 某一档原生解码/编码失败时，继续尝试下一档更低分辨率和质量，避免瞬时内存压力导致整次选择立即失败。
- 所有档位均失败时抛出受控上传处理错误，界面统一显示“图片处理失败，请重新选择或换一张图片”。
- 不向用户暴露原生异常、系统文件路径或内容 URI。
- 流式大图无论成功或失败，应用私有临时原图均由 `finally` 清理。
- 编码成功但没有更小结果时继续保留原图语义，不把它错误标记为已压缩。
- 文档、音频、视频及不可压缩图片类型仍不进入有损图片编码路径。
