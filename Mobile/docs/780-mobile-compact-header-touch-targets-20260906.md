# 780 · 移动端主框架紧凑图标与触控边界复验

> 日期：2026-09-06  
> 结论：工作台、消息、待办、通讯录顶部操作图标保持 18–21dp 的紧凑视觉尺寸，同时统一提供约 44×44dp 的透明触控区域。两台 Android 模拟器 Profile 包运行、自动化与全量回归均通过；连接的 realme 真机仍锁屏休眠，暂不把本项写成真机通过。

## 本次处理

- 新增共享的 `compactHeaderIconButtonStyle`，统一最小/最大触控区为 44×44dp，图标本身不放大。
- 接入工作台通知、消息收藏/群发/发起会话、待办新建和通讯录添加好友等顶部操作。
- 保留主标题、列表首项和系统状态栏之间的原有信息密度，不再通过放大可见按钮来满足点击区域。
- 为公共样式和主要入口增加精确尺寸断言，防止后续页面重新出现“大图标、大按钮”。

## 模拟器实测

在 Android Profile 包、420dpi 模拟器语义树中读取到：

| 入口 | 宽 × 高（dp） |
| --- | ---: |
| 工作台 · 通知 | 44.2 × 43.8 |
| 消息 · 收藏 | 44.2 × 43.8 |
| 消息 · 发起会话 | 43.8 × 43.8 |
| 待办 · 新建 | 44.2 × 43.8 |
| 通讯录 · 添加好友 | 43.8 × 44.2 |

像素到 dp 的换算存在不足 0.3dp 的取整误差，五个入口均达到约 44dp 的可点击区域，视觉图标仍保持紧凑。
