# 593 IM 操作抽屉统一

## 当前结论

群成员管理、消息长按操作和转发目标选择已统一为应用内移动端选择抽屉，不再各自维护系统默认弹层结构。

- 群成员管理显示成员姓名以及设为/取消管理员、禁言、转让群主、移出群聊；移出操作保持危险色，实际执行前仍有二次确认。
- 消息长按操作根据服务端消息配置和当前权限生成，单聊不显示“设为群置顶”，群聊才显示。
- 转发目标保留单聊/群聊类型标识，目标较多时自动提供搜索。
- 本轮只打开自动化抽屉并关闭，没有执行角色变更、禁言、移除、转发或消息修改。

## 真机边界

真机解锁后需要分别长按单聊消息、长按群聊消息、打开转发目标和群成员管理，检查抽屉高度、滚动、返回及单聊/群聊操作差异；不选择最终动作，不改变服务端数据。
