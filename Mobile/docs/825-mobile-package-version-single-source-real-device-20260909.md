# 移动端安装包版本单一来源与真机复验

日期：2026-09-09（Asia/Shanghai）

## 结论

登录页和“我的”此前各自写死 `v1.0.1`，而登录协议、心跳和更新检查读取实际安装包版本。同一客户端在以后升级构建后可能同时出现两个版本号。现已统一由 `package_info_plus` 读取已安装包版本，桌面端 `v1.0.105` 与移动端版本继续独立管理。

## 改造

- 新增 `AppVersionLabel` 和可覆盖的 `appVersionProvider`，登录页及“我的”共用该来源。
- 读取中不闪现伪造版本；“我的”读取失败时明确显示“版本信息不可用”。
- 视觉基准通过 provider 注入固定版本，避免平台插件缺失被误当成布局变化。

## 验证

- 动态版本、登录安全与完整页面视觉回归：22/22 通过。
- 13 张主页面视觉基准全部保持一致。
- 相关文件静态检查：0 issue。
- 当前完整 Flutter 回归：1417/1417 通过。
- Profile APK 构建成功并覆盖安装至 realme RMX3366；应用保留登录并正常进入工作台。

## 边界

本轮只证明移动端版本来源和 Android 真机展示一致，不代表桌面端当前可见窗口、iOS 安装包或完整多端同步矩阵已经通过。
