# 移动端工作台与全部应用真机验收

> 验收日期：2026-09-09  
> 设备：Android 真机  
> 数据基准：当前服务端工作台目录与真实待办

## 结论

本轮范围通过。

- 公告位于常用应用上方，并压缩为单行入口，没有占用大块首页空间。
- 移动端未展示无法在移动端使用的常用站点。
- 没有日程数据时不渲染空日程模块。
- 常用应用与全部应用使用同一份服务端应用目录、名称、顺序、分类和路由，不依赖旧桌面源码硬编码。
- 首页应用图标为五列紧凑布局，长名称最多两行；应用卡片没有多余外边框。
- 首页待办只展示前三条真实事项，处理入口保持紧凑；完整待办由“查看全部”进入。
- 全部应用按考勤、费用、财务、采购、行政分组，当前服务端目录共展示打卡、请假、加班、出差、补卡、考勤申诉、报销、请款、借支、采购和用印入口。
- 工作台底部保持工作台、消息、待办、通讯录、我的五个主标签，并显示真实待办角标。
